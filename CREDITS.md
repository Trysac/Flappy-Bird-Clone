# Credits

Everything in this repository is original work made for this project; no third-party
assets are included.

| Asset | Where | How it was made |
|---|---|---|
| Dragon, rock gates, coins, ground, hills, mountains, clouds | `Assets/Scripts/Game` | Low-poly meshes built in code at run time (`LowPoly.cs`) |
| Materials, particle texture, sky | `Assets/Art` | Generated by `Assets/Editor/ProjectBuilder.cs` |
| Sound effects and music | `Assets/Audio` | Synthesized by `tools/audio` (Python standard library, encoded with ffmpeg) |
| Font | — | Unity's default runtime font |

## Removed third-party content

Earlier versions of this repository (before the `fix/asset-licensing` changes) contained
Asset Store packages (Synty PolygonKnights, Bitgem, Special Skills Effects Pack, RPG Monster
Wave Polyart, BOXOPHOBIC, VR Water Shader, RainMaker), Kenney's UI pack and fonts, Bensound
music, and sound effects and sprites of unknown origin. They were removed because they came
from the Asset Store, whose EULA does not allow redistribution in a public repository, or
because their origin and licence were not recorded. They remain in the git history, which was not rewritten.
